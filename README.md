# The World in One Page — Sunday 22 November 2026

A newspaper front page that sums up Sunday 22 November 2026 in one image:
the COP31 climate talks closing in on a final deal in Antalya, leading seven
more stories from the Gulf, Ukraine, Mexico, the United States, Geneva and
Nigeria — each verified against Reuters, the Associated Press or Agence
France-Presse, and each first reported on that day.

`main.ts` copies the rendered page (`entry.png`, 1024×1024) into
`/output/entry.png`, checking the PNG magic bytes, the 1 MiB size cap and the
1024×1024 pixel cap first, so both grading runs write identical bytes.

Sources for every story are listed in `SOURCES.md`.
